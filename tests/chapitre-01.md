# Introduction

MDFusion est une application web progressive (PWA) qui fonctionne **100% hors-ligne**.

## Objectif

Permettre de convertir, fusionner et créer des documents Markdown directement dans le navigateur, sans envoyer aucune donnée à un serveur.

## Principes

- *Confidentialité* : tout reste en local
- **Performance** : conversion instantanée
- ~~Dépendance serveur~~ : aucune

> L'application est installable comme une app native depuis le navigateur.
