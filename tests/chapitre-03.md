# Guide d'utilisation

## Convertir des documents

1. Ouvrez l'onglet **Convertir**
2. Déposez vos fichiers dans la zone de dépôt
3. Cliquez sur `Convertir & fusionner`
4. Modifiez le résultat dans l'onglet **Édition**
5. Exportez en `.md` ou copiez dans le presse-papier

## Fusionner des Markdown

- Glissez vos fichiers `.md` dans la zone de dépôt
- Réordonnez-les par glisser-déposer
- Ajustez les séparateurs et niveaux de titre

## Éditeur

L'éditeur propose un mode <u>WYSIWYG</u> bidirectionnel :

- Écrivez en Markdown → l'aperçu se met à jour
- Modifiez l'aperçu → le Markdown se synchronise

### Raccourcis de la toolbar

| Icône | Action |
| --- | --- |
| H1–H5 | Titres de niveau 1 à 5 |
| **B** | Gras |
| *I* | Italique |
| ~~S~~ | Barré |
| `<>` | Code en ligne |

> Astuce : en mode **Aperçu** seul, le contenu devient directement éditable.
