# Formats supportés

## Documents

| Format | Extension | Librairie |
| --- | --- | --- |
| PDF | .pdf | pdfjs-dist |
| Word | .docx | mammoth |
| Excel | .xlsx | SheetJS |

## Données

1. **CSV** : tableaux de données
2. **JSON** : structures formatées
3. **XML** : données structurées

## Web et médias

- [ ] HTML vers Markdown
- [x] Images avec métadonnées
- [x] EPUB (livres numériques)

---

*Tous les formats sont convertis côté client.*
